# Stack-Attack-Kt
Stack Attack Kt — ностальгическая аркада по мотивам игры с кнопочных телефонов Siemens. Вы — грузчик на складе. Грейферы сбрасывают ящики, а вы должны выстраивать их в ряды. Полный ряд исчезает и приносит бонусные очки. Падение ящика на голову означает конец игры. Толкайте ящики, прыгайте, сбивайте их в полёте (на лёгких уровнях). Четыре режима сложности от спокойного до экстремального. Для каждого уровня ведётся своя таблица рекордов. Простое управление, классический геймплей, ретро графика.
